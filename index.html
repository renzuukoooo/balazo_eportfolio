03 / EVIDENCE & IMPACT

STAR Case Studies

Short examples showing how I approached a task, what I built, and what I learned from it.

CASE 01GAME LOGIC

Turning an Idea into an Interactive Browser Prototype

Situation
I wanted to explore how a simple game concept could become an interactive browser experience.
Task
Create a playable flow where player decisions produce different outcomes.
Action
Built the interface with HTML and CSS, then used JavaScript for player state, randomized outcomes, score, health, coins, win/lose conditions, button events, and restart behavior.
Result
Produced a functional browser prototype with 3 tracked player stats, multiple choice paths, randomized outcomes, and changing game states, giving me practical experience connecting design ideas with gameplay logic.
CASE 02RPG SYSTEMS

Designing a Beginner RPG Character-Creation Flow

Situation
I wanted to experiment with how player choices could shape the starting identity and attributes of an RPG character.
Task
Create a console-based character creation flow with clear choices and a final character summary.
Action
Implemented 3 class branches, 2 weapon options per class, Attack/Defense focus choices, and conditional assignment of Health, Strength, and Intelligence values.
Result
Produced a working C prototype with 3 class branches, 6 weapon options overall, 2 focus choices, and 3 tracked attributes, while identifying input validation as a future improvement.
